# Disease Co-occurrence Pattern Mining using Frequent Pattern Mining

## 📌 Project Overview

This project was developed as part of my **Research Internship** at **SRM University-AP**.

The objective of this project is to analyze healthcare datasets and discover diseases that frequently occur together using **Frequent Pattern Mining** techniques. By identifying disease co-occurrence patterns, the project aims to support disease prediction and healthcare data analysis.

---

## 🎯 Objectives

- Perform data preprocessing and cleaning on healthcare datasets.
- Discover frequent disease combinations.
- Generate association rules between diseases.
- Analyze disease co-occurrence patterns.
- Support explainable disease prediction through data mining techniques.
